### Descripción del Curso
El curso de Arquitectura de Software aborda el diseño, estructuración y patrones arquitectónicos necesarios para construir aplicaciones escalables, mantenibles y eficientes, aplicando buenas prácticas de desarrollo en Node.js y control de versiones con Git.

### Expectativas del Curso
* Comprender los principios de diseño de software e implementarlos en proyectos reales.
* Desarrollar habilidades para tomar e identificar decisiones de arquitectura organizadas (ADRs).
* Adquirir destreza en la construcción de APIs REST robustas utilizando Node.js y Express.
